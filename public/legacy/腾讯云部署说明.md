# 腾讯云公网部署说明

本项目是纯静态网站，可以直接部署到腾讯云 CloudBase 静态网站托管。

## 推荐方式：CloudBase 静态网站托管

1. 登录腾讯云控制台，并完成实名认证。
2. 进入「云开发 CloudBase」。
3. 创建一个环境，计费方式按你的账号提示选择即可。
4. 进入该环境的「静态网站托管」。
5. 开启静态网站托管。
6. 上传本目录中的网站文件，或者上传 `quantum-tunnel-web.zip`。
7. 确认根目录包含：
   - `index.html`
   - `styles.css`
   - `app.js`
   - `assets/robot_host_original.png`
8. 部署完成后，腾讯云会提供一个公网访问域名，通常类似：
   - `https://你的环境ID.xxx.tcloudbaseapp.com/`

## 自定义域名

如果需要使用自己的域名：

1. 在 CloudBase 静态网站托管中添加自定义域名。
2. 到域名 DNS 控制台添加腾讯云提示的 CNAME 解析。
3. 开启 HTTPS 证书。
4. 等待解析生效后，即可通过自己的域名访问。

## 注意事项

- 不要上传 `tunnel.log`。
- `localhost:8765` 只适合本机预览，不能作为公网链接。
- 本网站没有服务端和数据库，部署时不需要云服务器 CVM。
